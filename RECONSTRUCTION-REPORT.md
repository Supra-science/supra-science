## 1. Why this reconstruction exists

The 2026-11-08 live deployment of the Supra-Science platform was published from a Muse account that the owner later deleted. The original source is gone. The only surviving copy of the November 8 version is the live deployment itself (Cloudflare Worker `supra-science`, last deployed 2026-11-08 17:36:39 UTC via Wrangler, version `69e7f87a-ecc3-453b-af52-78fd5f9d5e4c`).

The closest available base was the November 5 source (302 KB package: `supra-science-platform-integration/`, 101 files). The live deployment is newer than that base in material ways: it has a `/book` route, service prices, images, reCAPTCHA, Gmail/Calendar OAuth, and an Arabic-first root — none of which exist in the November 5 files. Deploying from the November 5 files would regress the live site, so the November 8 version was rebuilt from the deployed code.
